# 退款政策

文档编号：POL-REFUND-001

## 到账时间

退款审核通过后，款项将在 3 到 7 个工作日内退回原支付账户。

- 银行卡：通常 3 到 7 个工作日
- 钱包支付：通常 1 到 3 个工作日
- 货到付款：退回顾客填写的银行卡，可能需要 7 个工作日

退款状态为 PROCESSING 表示财务正在打款，不是失败。

退款状态为 COMPLETED 表示已发起打款，具体入账仍取决于银行。

退款状态为 REJECTED 表示申请未通过，需要人工客服说明原因。

## 退款金额

退款金额以实付金额为准，优惠券、积分按活动规则折算。运费是否退还见配送政策。

## 谁能查退款

客服只能查询当前登录用户自己的退款单，不能查询他人订单。
